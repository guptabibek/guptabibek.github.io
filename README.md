## About this repository

The portfolio is a lightweight, responsive **HTML, CSS, and JavaScript** website hosted with GitHub Pages. It includes selected project case studies, professional experience, and contact information.

- `index.html` — home page and case-study overview
- `styles.css` — responsive design and light/dark themes
- `script.js` — navigation, theme toggle, local-time display, and motion effects
- `assets/` — site imagery, fonts, and résumé assets
- `work/` — additional project material

To view locally, open `index.html` in your browser or serve the directory with a static file server:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).
